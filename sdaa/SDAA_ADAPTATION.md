# DeepDegradome 龙芯 SDAA 适配与验证

## 1. 结论摘要

DEVELOP 生成器与 DeepPROTACs 评价器已接入 SDAA，分子处理、结构准备和对接工具运行于 CPU。原始模型权重直接载入，不重新训练。

- 功能：官方评价输入、公共 PDB 主链路、固定复合体单候选 iFitDock 示例均已实际完成。
- 后续修复：共同 Chimera 准备规则与 Rosetta 非 Pro 近零角度分类补丁已合入完整运行环境；完整示例两端都采用修复版 Rosetta。
- 固定输入精度：DEVELOP 默认路径未过原概率误差门槛，强制 FP32 的所测状态通过；DeepPROTACs 分类、投票和保留决定一致。
- 修复版整体结果：主链路最终保留 6／2，成功阶段合计约 30.966／59.004 分钟；iFitDock 示例保留 0／0，约 11.258／28.719 分钟。均为 CUDA／x86 在前、SDAA／龙芯在后，每组一轮，不作为公平硬件速度比。

已完成官方评价输入、公共 PDB 主链路，以及固定复合体单候选 iFitDock 实验。整链功能可运行，尚未达到跨平台全流程严格等价。

## 4. 精度与输出一致性

### 4.1 修复版整体流程

以下为共同 Chimera 准备规则及近零分类修复合入后的完整运行。两端 Rosetta 均带同一近零补丁，CUDA 是修改后的参考；CUDA DEVELOP 沿原 TF1 路径，龙芯 DEVELOP 使用 `TORCH_SDAA_CONV_USE_FP32=0`，且龙芯真实采样启用结构缓存。

主链路为准备 → PatchDock → Rosetta → DEVELOP → 原手性／化学／结构后处理 → DeepPROTACs。它不串接实验分支的 iFitDock 结合能评分。原后处理中对应构象优化走 UFF，不能把实验 MMFF 对照直接当作该处全部输入的验收。

| 公共 PDB 主链路指标 | CUDA／x86 | SDAA／龙芯 |
| --- | ---: | ---: |
| 全局姿态／Rosetta 尝试 | 10／20 | 10／20 |
| 接受精修构象 | 18 | 18 |
| 实际生成姿态 | 5 | 4 |
| 生成／可解析／单连通输出行 | 1250／1250／1250 | 1000／1000／1000 |
| 进入后处理的原始行 | 100 | 80 |
| 通过结构筛选／进入评价 | 12／12 | 11／11 |
| 最终保留 | 6 | 2 |

每个可用 linker 长度采样 50 个，每个可用姿态的前 20 行原始结果进入后处理。两端输入哈希相同，但中间结构与候选集合不同。最终分子经同一 RDKit 2021.09.4 后端规范化，去普通显式氢与 atom map，保留立体、电荷、同位素及互变异构图；CUDA 6 个、龙芯 2 个，交集 0、并集 8。这些计数不是实验准确率，写出行全部可解析也不等于所有内部尝试的合法率。

固定复合体实验从同一份准备后特征重新生成，并按排序处理一个候选。它不分别重新运行 Rosetta，也不使用 DeepPROTACs；16 表示受约束构象初始化尝试数，随后用 MMFF94 局部精修，并非接受精修 16 轮：

| iFitDock 实验指标 | CUDA／x86 | SDAA／龙芯 |
| --- | ---: | ---: |
| 新生成行数 | 250 | 250 |
| 去重候选 | 205 | 186 |
| 实际处理候选 | 1 | 1 |
| 数值评分姿态 | 0 | 2 |
| 最终保留 | 0 | 0 |
| 结束状态 | 明确无姿态 | 有评分后被几何检查剔除 |

该分支两端所选分子图不同，首次确认的输出分歧已经出现在新鲜 DEVELOP 生成阶段；后续不同分子的能量不能相减当作平台误差。最终均保留 0 不构成数值等价证明。

龙芯两个评分姿态的 deltaG 为 −15.7669／−18.1796，但最大片段 RMSD 为 9.0557／8.9828 Å、最短蛋白重原子距离为 0.7760／0.6363 Å，因片段偏离与碰撞淘汰。受体固定并不固定配体两端片段；该实验仍需评估片段约束及完整 PROTAC 评分阈值的适用性。

## 5. 性能

### 5.1 修复版完整流程单次观测

本节对应第 4.1 节同一批修复后运行，**不是**第 5.4 节的旧固定姿态控制例，也不是原始程序与修复程序的成对提速实验。Chimera 共同规则和 Rosetta 近零补丁均已包含；生成仍为默认卷积路径。

计时为各成功阶段墙钟之和，包含启动、载入、处理和写出；排除资源等待、失败尝试及人工诊断。每端每条链路各一轮。

| 主链路阶段 | CUDA／x86 秒（占比） | SDAA／龙芯秒（占比） |
| --- | ---: | ---: |
| 准备 | 41.821（2.25%） | 72.821（2.06%） |
| 全局对接 | 136.272（7.33%） | 329.048（9.29%） |
| Rosetta 精修 | 218.128（11.74%） | 464.050（13.11%） |
| DEVELOP 生成 | 475.885（25.61%） | 1540.153（43.50%） |
| 结构及化学筛选 | 976.129（52.54%） | 1103.898（31.18%） |
| DeepPROTACs 评价 | 8.929（0.48%） | 29.106（0.82%） |
| 汇总 | 0.765（0.04%） | 1.166（0.03%） |
| 合计 | 1857.931（100%） | 3540.242（100%） |

| 固定复合体 iFitDock 实验 | CUDA／x86 秒 | SDAA／龙芯秒 |
| --- | ---: | ---: |
| 新生成阶段 | 76.176 | 209.785 |
| 单候选后处理阶段 | 599.285 | 1513.335 |
| 合计 | 675.461 | 1723.120 |

主链龙芯生成与原后处理分别占 43.50%／31.18%，评价占 0.82%；生成约占额外总耗时的 63%。生成阶段含 CPU 采样和化学处理，不能全部归为 SDAA 卷积耗时。

iFitDock 单候选后处理分解如下；“未执行”是受科学分支控制跳过，不填成同等工作量的 0 秒：

| 后处理阶段 | CUDA／x86 秒 | SDAA／龙芯秒 |
| --- | ---: | ---: |
| 构象初始化与 MMFF 精修 | 6.925 | 26.050 |
| 初次准备、网格与搜索 | 591.706 | 1105.895 |
| 完整 SA 参考 | 未执行：无评分姿态 | 1.166 |
| 保留邻域支持后的 SA 复算 | 未执行：无评分姿态 | 377.385 |
| 最终几何与能量检查 | 0.515 | 2.718 |

后处理还受不同配体的电荷准备及条件复算影响。候选与分支不同，以上只描述应用流程耗时，不计算硬件加速比；也不能把差额全部解释成 LATX 翻译成本。

### 5.2 神经网络固定输入基准

生成器固定输入、latent 及 dropout 随机量；CNN 缓存关闭；热身 5 对，五轮，每轮 20 对节点／边预测。包含主机输入／输出，不含进程启动及模型初始化。

| 组件 | CUDA 中位数 | SDAA 中位数 | CUDA／SDAA | SDAA 数值状态 |
| --- | ---: | ---: | ---: | --- |
| DEVELOP 默认路径，每对 | 13.862 [13.676–14.014] ms | 134.436 [134.233–135.330] ms | 0.1031 | 原概率门槛未通过 |
| DEVELOP 强制 FP32，每对 | 13.862 [13.676–14.014] ms | 2045.963 [2045.663–2046.823] ms | 0.0068 | 所测概率门槛通过 |
| DeepPROTACs，每轮 1950 次前向 | 7.419 [7.348–7.458] s | 113.491 [113.338–113.925] s | 0.0654 | 所测决策一致 |

评价器固定 195 个候选和十权重；输入与权重预先驻卡，完整热身一轮，再计时五轮并同步。评价器计时不含载入、构图和传输。

比值定义为 CUDA 中位数／SDAA 中位数，小于 1 表示 SDAA 耗时较长。对应 SDAA／CUDA 耗时约 9.70、147.59、15.30 倍，这是匹配软件栈的观察，不是纯芯片性能。范围为五轮最小–最大，不是置信区间。

### 5.3 结构缓存的独立性能对照

另一个同 Torch 实现的受控实验固定权重、输入与随机量，热身 3 对，五轮每轮 3 对，正常计时与 profiler 分开，边界前后同步。单位为 ms／节点＋边预测对：

**缓存＋FP32 已有上述固定前向测试；尚未单独验收的是当前生产配置下缓存＋FP32 的完整生成精度、首次成本及端到端吞吐。** 不能把未缓存约 147.59 倍套用到已缓存完整生成，也不能把约 31 倍缓存收益当作整链提速。
